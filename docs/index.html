A NOTE ON THE DATA

A reference, with context.

This directory reproduces the supplied 2025 CAS journal classification reference spreadsheet. It is an independent lookup tool, not an official CAS service or a live ranking.

CAS Division preserves the source’s 1–4 classification; these are not JCR quartiles. Top Journal and Open Access reproduce the source’s Yes/No flags. Subject categories, ISSNs and impact factors were not included in the source.
